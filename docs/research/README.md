## 2. Core Research Objectives

1. **Empirical Multi-Layer Validation**: Prove whether cross-layer correlation outperforms single-vector URL lexical inference.
2. **Missing-Layer Robustness**: Establish that system confidence gracefully accommodates absent layers without producing false alarms.
3. **Reproducibility**: Ensure all experimental configurations, datasets, random seeds, and metric computation scripts are preserved and verifiable via automated tests.
