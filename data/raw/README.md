# Dataset 1 — Malicious URL Classification Dataset

## Overview

This dataset contains 651,191 URLs classified into four categories:

- benign
- defacement
- phishing
- malware

The dataset is used for the initial machine-learning experiments
of the AI-powered multi-layer phishing detection project.

## Dataset Structure

The original dataset contains two columns:

| Column | Description |
|---|---|
| url | URL or web address |
| type | Security classification |

Example:

```text
url,type
br-icloud.com.br,phishing
mp3raid.com/music/krizz_kaliko.html,benign
